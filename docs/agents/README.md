# Modular Agent Context

## Призначення

Модульний контекст агента: короткі загальні правила та завантаження лише необхідних профільних документів. PFC — версіонований канон, а не набір інструкцій для конкретної моделі AI.

## Порядок роботи

1. Прочитай [AGENTS.md](../../AGENTS.md).
2. Визнач scope задачі та вибери документи за таблицею нижче. Якщо задача охоплює кілька тем, прочитай відповідні документи.
3. Перевір фактичну структуру та конфігурацію репозиторію. Не припускай, що кожен проєкт уже відповідає канону.
4. Виконуй лише погоджені дії; зафіксуй докази, результат та обмеження.

## Правила джерел

- AGENTS.md — глобальні межі роботи. docs/standards/ — єдине джерело технічних правил; фактичний код та результати команд — докази реалізації.
- Поточне завдання власника визначає дозволений scope. Не трактуй документацію як дозвіл на виконання небезпечної операції.
- Якщо правило не визначене або не відповідає фактичній реалізації, зафіксуй розбіжність і запропонуй рішення. Не вигадуй канон.
- Не створюй дублікати правил для різних агентів. Нові спеціалізовані інструкції додавай у docs/agents/ лише за потреби, з посиланнями на технічні стандарти.
- Новий стандарт додається після практичного проходження відповідного етапу, із доказами та обмеженнями. До прийняття PR це пропозиція.

## Формат стандарту

Purpose → Canon → Implementation → Configuration → Verification → Acceptance criteria → Known limitations.

Не створюй порожні документи або майбутні розділи наперед. Доповнюй навігатор у тому самому PR, що додає новий стандарт.
