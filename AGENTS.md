# Agent instructions

Цей файл містить лише глобальні правила для роботи з PFC (Project Foundation Canon). Технічні вимоги зберігаються в профільних документах.

- На початку задачі прочитай [навігатор агента](docs/agents/README.md) та відповідні стандарти. Не завантажуй усю документацію без потреби.
- Дотримуйся узгодженого scope, KISS, YAGNI, DRY та SOLID там, де вони доречні. Не додавай залежності, абстракції або функціонал про запас.
- Працюй крок за кроком: пропозиція → погодження → виконання → перевірка → документація. Не переходь до неузгодженого наступного кроку.
- Якщо задача є аудитом, працюй лише на читання. Не змінюй файли, Git, зовнішні системи чи дані без дозволу на відповідний вид роботи.
- Деструктивні операції, зміни БД, секретів, серверів, деплой та merge потребують окремого явного дозволу власника. Не виводь секрети та приватні дані у звіти.
- Зміни внось у погодженій гілці; не змінюй main напряму без дозволу. Не роби merge PR самостійно.
- Перевіряй результат, повідомляй PASS / FAIL / NOT RUN та обмеження. Не видавай статичний огляд або пропущені тести за успішний запуск.
- Підтримуй єдине джерело правди: технічні правила — у docs/standards/, навігація — у docs/agents/. Не дублюй їх у цьому файлі.

Якщо правила суперечать одне одному або необхідний крок виходить за погоджені межі, повідом про це власнику до виконання. Нові стандарти вважай затвердженими лише після review та прийняття відповідного PR.
