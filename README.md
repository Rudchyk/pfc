# PFC

Project Foundation Canon — Канон фундаменту проєкту.

## Підготовка середовища

Встановлення залежностей відповідно до зафіксованих версій:

```bash
pnpm install --frozen-lockfile
```

Git hooks автоматично ініціалізуються під час встановлення залежностей.

## Форматування

| Команда             | Призначення                                     |
| ------------------- | ----------------------------------------------- |
| `pnpm format`       | Форматування всіх підтримуваних файлів проєкту. |
| `pnpm format:check` | Перевірка форматування без внесення змін.       |

Для форматування використовується Prettier.

## Лінтинг

| Команда         | Призначення                                                       |
| --------------- | ----------------------------------------------------------------- |
| `pnpm lint`     | Перевірка коду на відповідність правилам ESLint.                  |
| `pnpm lint:fix` | Автоматичне виправлення помилок, які підтримують автовиправлення. |

## Git hooks

Husky та lint-staged автоматично перевіряють підготовлені до коміту файли:

- JavaScript та TypeScript — ESLint з автовиправленням, після чого Prettier.
- Інші підтримувані файли — форматування за допомогою Prettier.
- Невиправлені помилки лінтингу блокують створення коміту.
- Обробляються лише staged-файли.

Для ручної ініціалізації або відновлення Git hooks:

```bash
pnpm prepare
```

## Вебзастосунок (Next.js)

Вебзастосунок розташований у каталозі `apps/web`.
Для оркестрації задач монорепозиторію використовується Turborepo.

### Запуск та збірка

| Команда          | Призначення                                      |
| ---------------- | ------------------------------------------------ |
| `pnpm dev`       | Запуск усіх застосунків у режимі розробки.       |
| `pnpm dev:web`   | Запуск вебзастосунку в режимі розробки.          |
| `pnpm build`     | Збірка всіх workspace-пакетів із командою build. |
| `pnpm build:web` | Збірка вебзастосунку та його залежностей.        |
| `pnpm start:web` | Запуск зібраного вебзастосунку.                  |

Адреса локального вебзастосунку: http://localhost:3000

### Перевірка якості коду

| Команда                 | Призначення                                                     |
| ----------------------- | --------------------------------------------------------------- |
| `pnpm lint:web`         | Перевірка коду вебзастосунку за допомогою ESLint.               |
| `pnpm typecheck`        | Перевірка типів усіх workspace-пакетів із відповідною командою. |
| `pnpm typecheck:web`    | Перевірка типів вебзастосунку.                                  |
| `pnpm format:web`       | Форматування файлів вебзастосунку.                              |
| `pnpm format:check:web` | Перевірка форматування вебзастосунку без внесення змін.         |

### Standalone-збірка

```bash
pnpm build:web
pnpm start:web
```

Готовий артефакт: `apps/web/.next/standalone/`. Збірка копіює `public/` та `.next/static/` до каталогу `apps/web` всередині артефакту. Для розгортання переноситься весь standalone-каталог, а сервер запускається командою `node apps/web/server.js` з його кореня. Збірка повинна відповідати ОС та архітектурі цільового середовища. Порт задається через `PORT`, адреса прив'язки — через `HOSTNAME`.

### Базовий UI

- Світла, темна та системна тема; перемикач у header.
- Спільні header, main і footer, сторінки 404 та помилок, індикатор завантаження і skeleton.
- `useNotifier()` — черга сповіщень; виклик `notify('Повідомлення', 'success')`.
- `useGlobalLoading()` — початок операції повертає функцію завершення; викликати її у `finally`. Індикатор не приховується, доки всі активні операції не завершені.

Тести (Vitest, Playwright) і Lighthouse ще не підключено.
