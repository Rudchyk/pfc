# PFC

Project Foundation Canon — Канон фундаменту проєкту.

## Підготовка середовища

Встановлення залежностей відповідно до зафіксованих версій:

```bash
pnpm install --frozen-lockfile
```

Git hooks автоматично ініціалізуються під час встановлення залежностей.

## Форматування

| Команда             | Призначення                                     |
| ------------------- | ----------------------------------------------- |
| `pnpm format`       | Форматування всіх підтримуваних файлів проєкту. |
| `pnpm format:check` | Перевірка форматування без внесення змін.       |

Для форматування використовується Prettier.

## Лінтинг

| Команда         | Призначення                                                       |
| --------------- | ----------------------------------------------------------------- |
| `pnpm lint`     | Перевірка коду на відповідність правилам ESLint.                  |
| `pnpm lint:fix` | Автоматичне виправлення помилок, які підтримують автовиправлення. |

## Git hooks

Husky та lint-staged автоматично перевіряють підготовлені до коміту файли:

- JavaScript та TypeScript — ESLint з автовиправленням, після чого Prettier.
- Інші підтримувані файли — форматування за допомогою Prettier.
- Невиправлені помилки лінтингу блокують створення коміту.
- Обробляються лише staged-файли.

Для ручної ініціалізації або відновлення Git hooks:

```bash
pnpm prepare
```
